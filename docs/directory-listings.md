## Maintenance

Use a direct public product entry wherever available. Keep package indexes separate from directory/community features. Serve logo files locally under the existing CSP, preserve provenance and trademark ownership, and keep all external links opening in a new tab. Recheck claims before adding badges or changing approval wording. Do not display dynamic trust scores without a separate design for freshness and context.
