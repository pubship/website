02 / The boundaries matter

Your tools. Your account.
Your permission to connect.

Useful access starts with a clear boundary between the software you run and the Google account you authorize.

[ / ]

Open all the way through.

Inspect the code, run it yourself and share feedback. The project is AGPL-3.0-only licensed. There is no closed feature tier.

{ · }

Connected to your account.

Local tools use your own Google credentials. The project never receives them and does not operate a Google-connected service.

→ |

Clear about what it can do.

Tools start read-only. Optional local writes require explicit app access and a reviewed preparation. The API inventory records supported methods and the operation Google explicitly does not support. Review each tool's scope and limitations.

03 / Built in the open

The whole map.
Clear boundaries.

PubShip 0.24.0 implements 170 enabled methods from a pinned inventory of 172 definitions. Voided-purchase access is deliberately disabled. Google does not support subscription archiving. Implementation is not a claim of live verification.
