How it connects

Runs on your computer. Reaches Google with your access.

Local, not offline. PubShip calls Google directly and hands results to your client. No PubShip-run service sits in between.

Where you work

Your MCP client

Claude Code, Codex, Cursor, Gemini CLI or any stdio client

calls a toolgets the result

Local process

PubShip

On your computer, started with uvx pubship

HTTPS, your tokendata as returned

Source of the data

Google APIs

Android Publisher, Play Developer Reporting, bulk reports

Credentials

Your client config points to a key file on your disk. The project never receives it.

Permissions

Play Console permissions for your service account decide access. PubShip allowlists can only narrow them.

Results

Tool results go to your MCP client. Its own data handling applies.

Changes

Off by default. Each one is prepared, reviewed and applied once.

Clients

Works with the client you already use.

One local server, started with uvx pubship. Pick your client for the documented setup.

Claude Code

Add the server 
claude mcp add --transport stdio pubship -- uvx pubship

Documented command

Set GOOGLE_APPLICATION_CREDENTIALS and GOOGLE_PLAY_PACKAGES in the shell that launches Claude Code, then run /mcp to check the connection.

Full instructions on GitHub ↗

Codex

Add the server 
codex mcp add pubship -- uvx pubship
codex mcp list

Documented command

Set GOOGLE_APPLICATION_CREDENTIALS and GOOGLE_PLAY_PACKAGES in the shell that launches Codex. Desktop apps can use a different PATH from your terminal.

Full instructions on GitHub ↗

Get started

Four steps to your first read.

You need Python 3.11 or later, uv, an MCP client and access to your app in Play Console.

  1. 1

    Install uv

    uvx runs the published PubShip package.

    uv installation guide↗
  2. 2

    Set up Google access

    Your own service account, invited in Play Console. Read-only access is enough to start.

    How to set it up→
  3. 3

    Add it to your client

    Give it your key file path and app package names. Never the key itself.

    Client setup steps→
  4. 4

    Verify, then ask

    uvx pubship --check

    No credentials needed for the check. Then: “Show the production releases for com.example.app. Make no changes.”

Open the setup guide→ Let your agent install it↗
